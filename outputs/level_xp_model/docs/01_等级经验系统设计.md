# 等级经验系统设计

## 1. 核心定位

等级和经验值主要用于提供长期成长感，不建议直接等同于真实学习能力。

```text
等级系统：表达长期成长与投入
经验系统：记录完成 lesson、复习、任务等行为
能力评估：应由测验、正确率、掌握度等学习指标承担
```

## 2. 基础假设

- 用户初始等级为 Lv0
- 单 lesson = 10 XP
- 普通用户每天 3 个 lesson
- 深度用户每天 6 个 lesson
- 留存标准：次留 50%，7 留 35%，30 留 20%
- 当前等级上限：Lv100

## 3. 升级节奏设计方法

等级经验表不建议拍脑袋设定，而应从用户行为反推。

核心公式：

```text
预计累计 XP = 周期内完成 lesson 数 × 单 lesson XP
周期内完成 lesson 数 = 活跃天数 × 日均 lesson 数
```

对于普通用户：

```text
每日 XP = 3 × 10 = 30 XP
D1 XP = 30
D7 XP = 210
D30 XP = 900
D90 XP = 2700
D180 XP = 5400
D365 XP = 10950
```

因此等级锚点设计为：

| 周期 | 普通用户累计 XP | 目标等级 |
|---|---:|---:|
| D1 | 30 | Lv3 |
| D7 | 210 | Lv10 |
| D30 | 900 | Lv25 |
| D90 | 2700 | Lv45 |
| D180 | 5400 | Lv65 |
| D365 | 10950 | Lv100 |

## 4. Excel 表字段说明

| 字段 | 含义 |
|---|---|
| 等级 | 当前等级 |
| 累计 XP | 达到该等级至少需要的总 XP |
| 升级所需 XP | 从当前等级升到下一级需要的 XP |
| 约学习 lesson | 达到该等级大约需要完成多少 lesson |
| 普通用户约天数 | 普通用户每天 3 课，到达该等级大约需要多少天 |
| 深度用户约天数 | 深度用户每天 6 课，到达该等级大约需要多少天 |

公式：

```text
约学习 lesson = 累计 XP / 单 lesson XP
普通用户约天数 = 约学习 lesson / 普通用户每日 lesson 数
深度用户约天数 = 约学习 lesson / 深度用户每日 lesson 数
```

## 5. 注册 cohort 期望 XP

注册 cohort 期望 XP 是把流失用户也算进去后，一批注册用户平均每人预计产生的 XP。

它适合做整体经营估算，不适合直接设计单个活跃用户的升级门槛。

例子：

```text
100 个新注册用户
D1 留存 50%
普通用户每天 30 XP

D1 总 XP = 100 × 50% × 30 = 1500 XP
平均到每个注册用户 = 15 XP
```

因此：

```text
活跃用户 XP：用于设计等级节奏
注册 cohort 期望 XP：用于估算整体经验产出和系统通胀
```
