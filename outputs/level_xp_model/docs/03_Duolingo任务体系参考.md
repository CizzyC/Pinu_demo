# Duolingo 任务体系参考

## 1. 说明

Duolingo 的任务体系不是完全公开、固定的官方配置，任务类型会随地区、端、订阅状态和 A/B 实验变化。以下内容基于公开资料、产品观察和用户社区信息归纳，用于产品设计参考。

## 2. 每日任务 Daily Quests

Duolingo 每天通常给用户 3 个 daily quests，完成后给宝石、经验加成、任务进度等奖励。

| 类型 | 常见任务例子 | 设计目的 |
|---|---|---|
| 完课型 | 完成 1 / 2 / 3 节 lesson | 拉动基础学习行为 |
| XP 型 | 获得 10 / 20 / 30 / 50 XP | 拉动学习量 |
| 正确率型 | 完成 1 节 90%+ 正确率 lesson | 防止乱刷 |
| 完美表现型 | 完成 1 节 perfect lesson | 鼓励认真答题 |
| 连续学习型 | 完成今日学习，延续 streak | 强化每日回访 |
| 复习型 | 完成 practice / review | 推动复习 |
| 错题修复型 | 复习错题 / 修复 mistakes | 提升学习质量 |
| 内容探索型 | 完成 story / speaking / listening 练习 | 让用户体验不同内容 |
| 进度推进型 | 完成路径上的下一个 lesson | 推动主线进度 |
| 限时挑战型 | 完成 timed challenge | 拉动高强度短时活跃 |
| 社交互动型 | 好友互动相关任务 | 增加关系链触点 |

每日任务特点：

```text
低门槛
短周期
即时反馈
让用户知道今天该做什么
```

## 3. 每周任务 Weekly

Duolingo 典型的周周期机制包括 Friends Quest 和 League。

| 类型 | 常见任务例子 | 设计目的 |
|---|---|---|
| 好友协作型 | 和好友共同完成 X 节 lesson | 社交承诺 |
| 好友 XP 型 | 和好友共同获得 X XP | 拉动活跃量 |
| 好友质量型 | 和好友完成 X 节高正确率 lesson | 防止低质量刷课 |
| 排行榜型 League | 一周内获得 XP，进入晋级区 | 竞争驱动 |
| 保级型 | 避免掉入降级区 | 防流失、防掉队 |
| 晋级型 | 进入前 N 名升入更高联赛 | 长线竞争目标 |
| 周挑战型 | 一周完成若干任务 / lesson / XP | 给中周期目标 |

每周任务特点：

```text
比每日任务更重
适合绑定社交、竞争或稳定学习天数
用于提升一周内多次回访
```

## 4. 每月任务 Monthly

Duolingo 的 monthly challenge 常见形式是完成一定数量的 quests，获得月度 badge。

| 类型 | 常见任务例子 | 设计目的 |
|---|---|---|
| 月度徽章型 | 本月完成 30 / 40 / 50 个 quests | 长周期收集目标 |
| 月度 XP 型 | 本月获得 X XP | 拉动学习总量 |
| 月度活跃型 | 本月学习 N 天 | 强化习惯 |
| 月度完课型 | 本月完成 N 节 lesson | 拉动课程进度 |
| 月度主题型 | 每月一个主题 badge | 增加收藏感和稀缺感 |
| 月度元任务型 | 完成每日任务累计进度 | 把日活转化为月目标 |

每月任务特点：

```text
不适合太重 XP 奖励
更适合徽章、称号、头像框、收藏品
核心价值是长期收集感
```

## 5. 对当前产品的推荐结构

每日任务：

| 任务 | 示例 |
|---|---|
| 基础完成 | 完成 1 个 lesson |
| 学习质量 | 完成 1 个正确率 >= 80% 的 lesson |
| 轻度推进 | 今日累计完成 3 个 lesson 或获得 30 XP |

每周任务：

| 任务 | 示例 |
|---|---|
| 稳定学习 | 本周学习 4 天 |
| 学习量 | 本周完成 15 个 lesson |
| 质量任务 | 本周完成 5 个高正确率 lesson |

每月任务：

| 任务 | 示例 |
|---|---|
| 月度徽章 | 本月完成 40 个每日任务 |
| 月度学习 | 本月学习 20 天 |
| 月度完课 | 本月完成 80 个 lesson |

第一版建议：

```text
每日：完课 + XP + 正确率
每周：学习天数 + 完课数
每月：完成每日任务数换徽章
```
