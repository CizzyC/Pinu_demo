# 任务系统指标

## 1. 任务系统是否能提升活跃和留存

任务系统可以提升学习用户的活跃和留存，但前提是任务驱动真实学习行为，而不是只驱动领任务、刷奖励。

```text
等级系统：提供长期成长感
任务系统：告诉用户今天/这周具体做什么
```

任务系统主要影响：

| 目标 | 任务系统怎么影响 |
|---|---|
| D1 留存 | 新用户第二天回来完成任务 |
| D7 留存 | 每日任务 + 周任务形成短周期牵引 |
| D30 留存 | 月任务、徽章、连续完成感形成长期目标 |
| 学习频次 | 用户每天有明确学习动作 |
| 学习量 | 通过 lesson / XP / 周目标增加完成数 |
| 学习质量 | 通过正确率、复习、错题任务引导认真学习 |

## 2. 核心指标

| 指标 | 为什么重要 |
|---|---|
| D1 留存 | 判断任务是否让新用户愿意回来 |
| D7 留存 | 判断每日/周任务是否形成一周习惯 |
| D30 留存 | 判断月任务和长期目标是否有效 |
| 人均每周有效 lesson 数 | 判断任务是否真的带来学习量 |
| 任务完成用户的后续留存 | 判断完成任务是否影响继续学习 |

重点看：

```text
任务完成用户 vs 未完成用户 的 D1 / D7 / D30 留存差异
```

## 3. 任务系统漏斗

```text
任务曝光 -> 任务查看 -> 任务开始 -> 任务完成 -> 奖励领取 -> 次日回访
```

| 漏斗环节 | 指标 |
|---|---|
| 曝光 | 任务入口曝光率 |
| 查看 | 任务面板点击率 |
| 理解 | 任务开始率 / 任务相关行为开始率 |
| 完成 | 单任务完成率 |
| 领取 | 奖励领取率 |
| 复访 | 完成任务后次日留存 |

判断方法：

```text
曝光高、查看低：入口或文案弱
查看高、完成低：任务太难或不清楚
完成高、领取低：奖励反馈弱或领取入口弱
领取高、复访低：奖励没有形成后续动机
```

## 4. 每日任务指标

| 指标 | 看什么 |
|---|---|
| 每日任务完成率 | 任务难度是否合适 |
| 每日 3 任务全完成率 | 是否有挑战但不过重 |
| 首个任务完成率 | 入门任务是否足够轻 |
| 日均 lesson 数 | 是否提升学习量 |
| 日均学习时长 | 是否提升活跃时长 |
| 当日任务完成后继续学习率 | 任务是否带动更多学习 |
| 次日留存 | 完成任务后是否更愿意回来 |

建议目标：

```text
首个每日任务完成率：50%-70%
全部每日任务完成率：15%-35%
```

## 5. 每周任务指标

| 指标 | 看什么 |
|---|---|
| 周任务完成率 | 周目标是否合理 |
| 每周学习天数 | 是否从 1-2 天提升到 3-4 天 |
| 周活跃用户 WAU | 是否带动周活跃 |
| 周内回访次数 | 用户是否多次回来 |
| 周任务临近截止活跃 | 是否产生周末冲刺 |
| 周任务完成后下周留存 | 是否形成循环 |

建议目标：

```text
周任务完成率：20%-40%
每周学习 >= 3 天用户占比提升
```

## 6. 每月任务指标

| 指标 | 看什么 |
|---|---|
| 月任务参与率 | 用户是否理解月目标 |
| 月任务完成率 | 目标是否过高 |
| 月中进度分布 | 是否大多数用户早早放弃 |
| 月末冲刺率 | 是否有长期牵引 |
| 月度徽章领取率 | 收集奖励是否有吸引力 |
| 连续月完成率 | 是否形成长期习惯 |

建议目标：

```text
月任务完成率：10%-25%
连续 2 个月完成率逐步提升
```

## 7. 学习质量指标

| 指标 | 风险信号 |
|---|---|
| lesson 正确率 | 任务上线后下降 |
| 单课用时 | 明显变短 |
| 跳过率 | 上升 |
| 重试率 | 上升 |
| 错题复习率 | 下降 |
| 完成后测验表现 | 没有提升 |
| 重复刷同一课比例 | 上升 |

危险组合：

```text
任务完成率上升
lesson 数上升
但正确率下降
单课用时下降
重复刷课上升
```

## 8. 推荐北极星指标

不要用任务完成数当北极星。更建议用：

```text
每周有效学习用户数
```

定义示例：

```text
一周学习 >= 3 天
且完成 >= 5 个 lesson
且平均正确率 >= 70%
```
