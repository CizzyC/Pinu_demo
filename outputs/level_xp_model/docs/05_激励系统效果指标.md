# 激励系统效果指标

## 1. 等级、经验、任务是否能提升留存

等级、经验和任务系统可以提升学习用户活跃与留存，但它们提升的是继续学习的动机和反馈感，不直接等同于学习效果。

```text
等级：长期成长感
经验：行为反馈和进度量化
任务：短中期目标和行动指引
双倍卡：阶段性加速和奖励刺激
```

它们最容易提升：

```text
短期活跃：今天多上一课
中期留存：明天/这周愿意回来
长期习惯：用户觉得自己有积累，不想中断
```

但也可能带来风险：

```text
用户为了 XP 乱刷课
只在有双倍卡时学习
等级太快失去目标
等级太慢没有反馈
真实学习质量下降
```

## 2. 核心判断指标

| 指标 | 看什么 |
|---|---|
| D1 留存 | 新用户第二天是否回来 |
| D7 留存 | 是否形成一周内的学习惯性 |
| D30 留存 | 是否支撑长期成长 |
| DAU / WAU / MAU | 活跃规模是否提升 |
| 人均学习天数 | 用户一周/月内回来几天 |
| 人均 lesson 数 | 用户是否多学了 |
| 完课率 | 是否真的完成学习 |
| 学习时长 | 活跃是否变长 |
| 连续学习天数 | 习惯是否形成 |

## 3. 等级系统专项指标

| 指标 | 判断 |
|---|---|
| D1 等级分布 | 新用户首日是否获得反馈 |
| D7 等级分布 | 一周后是否有成长感 |
| D30 等级分布 | 中期是否还有空间 |
| 每日升级人数占比 | 升级反馈是否太稀或太频繁 |
| 平均升级间隔 | 用户多久升一级 |
| 卡在某等级的人数 | 是否某个门槛过高 |
| Lv100 达成率 | 是否过快满级 |
| 等级与留存相关性 | 高等级用户是否更留存 |

当前目标：

```text
D1 普通用户达到 Lv2-Lv3
D7 普通用户达到 Lv8-Lv12
D30 普通用户达到 Lv20-Lv30
Lv100 不应在短期内大量出现
```

## 4. 经验系统专项指标

| 指标 | 判断 |
|---|---|
| 人均每日 XP | 整体经验增长速度 |
| XP 来源占比 | XP 来自 lesson、任务、bonus 还是双倍卡 |
| 单用户 XP 方差 | 是否被少数深度用户拉高 |
| 重复刷课 XP 占比 | 是否有刷经验行为 |
| bonus XP 占比 | 奖励是否过强 |
| 双倍 XP 占比 | 经验通胀是否失控 |
| XP 与完课率关系 | XP 是否带来真实学习 |

警戒线：

```text
双倍 XP 占总 XP 10%-20%：健康
双倍 XP 占总 XP >25%：偏高
重复刷课 XP 占比过高：需要限制
```

## 5. 学习质量指标

| 指标 | 看什么 |
|---|---|
| lesson 正确率 | 用户是否认真学 |
| 满分率 | 是否变好或异常升高 |
| 重试率 | 是否乱点后重来 |
| 跳过率 | 是否为了 XP 快速跳过 |
| 单课用时 | 是否明显变短 |
| 复习完成率 | 是否愿意回顾 |
| 后续测验表现 | 学习效果是否提升 |

危险信号：

```text
lesson 数上升
但正确率下降
单课用时下降
跳过率上升
```

这说明用户可能在刷经验，不是在学习。

## 6. 推荐 A/B 测试

| 组别 | 机制 |
|---|---|
| A 组 | 无等级 / 无 XP / 无任务 |
| B 组 | 有等级 + lesson XP |
| C 组 | 有等级 + lesson XP + 任务 |
| D 组 | 有等级 + lesson XP + 任务 + 双倍卡 |

核心比较：

```text
D1 / D7 / D30 留存
人均 lesson 数
人均学习天数
完课率
正确率
奖励 XP 占比
```

如果激励组提升留存和 lesson 数，但正确率不下降，说明机制健康。

## 7. 推荐北极星指标

不要用 XP 或任务完成数当北极星。

推荐：

```text
Weekly Effective Learners
```

定义示例：

```text
一周内完成 >= 5 个 lesson
且平均正确率 >= 70%
的用户数
```

更严格版本：

```text
一周学习 >= 3 天
且完成 >= 5 个 lesson
且平均正确率 >= 70%
```

一句话原则：

> 激励系统的目标不是让用户多拿 XP，而是让用户多回来、认真学、持续学。
